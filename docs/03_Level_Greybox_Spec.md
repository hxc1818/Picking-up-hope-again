# 《Picking up hope again（重拾希望）》灰盒关卡设计规范 (v2.0)

> **版本**：v2.0（两段式 4 小时新手教程 + 独立战斗舞台）  
> **核心准则**：区分“大地图探索区”与“专用独立战斗擂台”，补充管道、灯光、碎屑、门禁与建筑细节，消除单调空旷感。

---

## 1. 空间划分与专属战斗舞台

### 1.1 独立战斗舞台 (Turn-Based Combat Arena)
- **功能定位**：专门用于承载所有回合制战斗的平坦隔离空间，防止大地图通道狭窄或地形落差导致角色与怪物模型穿模卡死。
- **空间尺度**：长 28 × 宽 24 × 高 14 格。
- **场地布局**：
  - 地面采用深色工业防滑板与发光引导线划分站位（我方 4 人一字站位标线、敌方最多 5 个站位标线）。
  - 可按场景切换两种氛围背景：飞船内部金属舱壁舞台 / 极寒冰原露天矿台舞台。

### 1.2 大地图探索空间标准
- **星舰内部通道**：宽 6~8 格，高 4~5 格。顶部加装闪烁警示灯带、壁挂散热管道、电缆槽与破损金属栅栏，两侧设置可供检查的维修终端与上锁储物柜。
- **科考站与矿坑区域**：开阔雪谷与工业钢架结构，铺设架空电缆、防风挡板、货运升降平台与清晰的主路导向灯柱。

## 2. 两段式新手教程灰盒关卡流（约 4 小时）

### 前半段：飞船受损与逃生（约 2 小时）
1. **静息休眠舱室**：昏暗应急红光、半开启的休眠柜、散落的工具箱与入门日志终端。
2. **泄压破损走廊**：变形的隔断墙、冒出白色蒸汽的断裂管道、在固定路径巡逻的失控清扫机与安保无人机。
3. **阀门与配电中继室**：解救第 1 名免费队友（巡检员·气属性·对群），带有需手拉闸门恢复通电的简单通路开关。
4. **下层动力机房**：救出第 2 名免费队友（医疗员·水属性·治疗），大型散热柱与备用发电机组，通往**轨道逃生舱发射井**。

### 后半段：迫降冰原与科考站（约 2 小时）
1. **坠机冰裂谷**：插在雪堆里的受损逃生舱残骸、散落补给箱、高耸冰壁形成的单向探索峡谷。
2. **废弃地面科考站**：包含安全屋休息站（内置模拟训练终端、材料合成台与装备强化工台）、被雪半埋的生活板房、需通电解锁的配电门禁房。
3. **地下工业采掘矿坑**：通过大型货运升降台下行，分布铁轨、废旧矿车、钢架走廊与旧式护卫机械群。
4. **矿坑深处决战厅与通讯塔**：宽阔的圆盘型矿坑底部，安置待机中的双阶段 Boss **【大型工程挖掘机】**，击破后通向顶部可重新连线母舰的**深空通讯塔**。

## 3. 灰盒白模与环境细节规范（Minecraft 1.18.2）

在全套精细模型置换前，明确区分功能区块并丰富陈设细节：
- **基础可行走甲板 / 雪地**：灰色混凝土、磨制深板岩 / 雪块、浮冰。
- **结构墙体与承重柱**：黑色混凝土、切制铁块、深板岩砖。
- **交互机关 / 通电开关 / 阀门**：黄色混凝土、红石灯、拉杆与按钮控制台。
- **环境装饰与氛围补充**：铁栏杆电缆、末地烛/避雷针管线、铁活板门通风口、营火/白雾粒子模拟漏气蒸汽。
- **巡逻怪物刷新点**：红石块隐藏于地面下方作为逻辑坐标锚点。
