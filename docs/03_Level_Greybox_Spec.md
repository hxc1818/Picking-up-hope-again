# 《Picking up hope again》灰盒关卡设计规范与流程标准 (Level Greybox Spec)

> **版本**：v1.0  
> **设计准则**：在铺设精细美术资产前，先以灰盒（Greybox / Whitebox）白模搭建场景几何体，验证战斗空间尺度、掩体布局、跑图动线与传送锚点节奏。

---

## 1. 关卡尺度与视线规划标准

| 空间类型 | 推荐尺寸 (长×宽×高) | 核心设计诉求 | 视线与引导目标 |
| :--- | :--- | :--- | :--- |
| **星舰主通道** | 宽 6~8格，高 4~5格 | 满足 4人跑动与第三人称相机回弹距离，避免相机穿模入墙 | 顶端黄色应急灯带导向，尽头为重工业气闸门 |
| **工会聚变大厅 (战斗中庭)** | 40×40格以上，高 12~16格 | 能够容纳多波次机械哨兵、重型外骨骼精英怪，有高低落差跳跃平台 | 中央巨大聚变管道发光柱，提供高辨识度地标 |
| **极寒异星采矿坑** | 80×80格开阔盆地 | 远距离掩体战、翻滚冲刺空间、重型钻探机与运输轨道 | 远处悬挂于天际的母舰阴影与地表信标塔 |

## 2. 灰盒关卡推进章节规划

### 序章：冷冻休眠舱唤醒（Tutorial Zone）
- **场景特征**：狭窄破损的休眠舱室 $\to$ 破损走廊 $\to$ 维修控制台。
- **验证机制**：
  1. 视角初始化与基本移动；
  2. 拾取第 1 把近战体素武器（重工扳手/等离子切刀）；
  3. 遭遇第 1 只失控清扫机器人，教学平A连击与翻滚；
  4. 解锁第 1 个【星舰传送锚点】，体验 F 键激活与快速治疗。

### 第一幕：下层重工业工会区（The Underdeck Engine Sector）
- **场景特征**：流浪地球地下城既视感，充满横纵金属管道、工人集市、重卡维修车间。
- **核心剧情**：与机械工会会长接头，调查主反应堆燃料失窃案。
- **战斗灰盒**：在蒸汽弥漫的配电站清理被骇入的安保机甲，教学战技（E）与终极大招（Q）充能循环。

### 第二幕：近地轨道空投与极寒异星地表（The Permafrost Mine）
- **场景特征**：走出星舰舱门，强冷空气风暴与雪原，废弃先驱采矿站。
- **核心玩法**：在极低温恶劣环境下寻找聚变替代矿石，双层地形立体战斗，第 1 个世界 Boss【先驱重型挖掘机甲】。

## 3. 灰盒白模选材标准（Minecraft 1.18.2）

在正式材质包与模型就绪前，严格使用以下原版方块划分功能区：
- **行走地面 / 道路**：灰色混凝土 (`minecraft:gray_concrete`)
- **不可逾越建筑墙体**：黑色混凝土 (`minecraft:black_concrete`)
- **交互机关 / 闸门**：黄色混凝土 (`minecraft:yellow_concrete`)
- **高低差爬梯 / 掩体**：铁块 (`minecraft:iron_block`) / 光滑石台阶
- **传送锚点占位桩**：青金石块 (`minecraft:lapis_block`)
- **敌人生成锚点 (Spawners)**：红石块 (`minecraft:redstone_block`)
