# 《Picking up hope again（重拾希望）》游戏系统设计说明书 (GDD)

> **项目名称**：Picking up hope again（重拾希望）  
> **引擎底座**：Minecraft 1.18.2 Forge 40.3.0  
> **核心类型**：太空重工业科幻 · ARPG 重主线冒险整合包

---

## 1. 世界观与故事梗概

### 1.1 背景设定
母星遭遇毁灭性引力天灾与极端降温，人类耗尽全部行星级工业力量建造了世代级超大型星舰——**“重拾希望号”（The Resilient Hope）**。
数万人在庞大的星舰内部沉睡或在各舱区繁衍生存。星舰的内部结构如同《流浪地球》中的地下城：粗大的聚变管道、厚重防爆闸门、蒸汽与机油气味弥漫的重工业生活区。

### 1.2 核心冲突：三方阵营博弈
星舰已在深空中航行了数个世代，随着核心重元素聚变炉燃料告急，舰内三方势力爆发尖锐冲突：
1. **【舰桥指挥层】（秩序与军事配给派）**：
   - 主张实施战时军事管制，削减下层居民配给，全舰进入深度休眠以维持飞船寿命。
2. **【底层机械工会】（重工平民与工程师派）**：
   - 由负责日夜维护聚变炉和重型机械的工人们组成，反对严苛配给，要求知情权，并主张停靠附近矿石星开采自救。
3. **【深空科学/生态派】（先驱科技与基因适应派）**：
   - 探索外星先驱文明遗留的能量核心与生物样本，甚至主张通过基因融合强化人类体魄以适应极寒与深空辐射。

玩家扮演一名在底层休眠舱被意外提前唤醒的“旧时代外勤特工”，在三方势力的交锋与暗流中被卷入主线，逐步查明聚变炉异常的真相，带领小队穿越星舰各个禁区，并空降至周边死星矿脉寻找人类文明重生的火种。

## 2. 核心操作与战斗架构

- **视角系统**：默认锁定第三人称越肩视角，强化动作观察与大局观。
- **动作底层**：引入 `Better Combat` 动作模组，武器带有平滑轻重连击轨迹、攻击前后摇与翻滚闪避无敌帧。
- **4人小队轮切 (Team Swap)**：
  - 玩家按 `1` / `2` / `3` / `4` 键瞬间切换出战角色。
  - 每个角色拥有独立血量（HP）、能量槽（Energy）、战技冷却时间。
  - 前台角色承受攻击，后台角色可触发协同攻击或提供增益光环。
- **战技与爆发技能**：
  - `E 键`：科技战技（产生量子能量球，短CD）。
  - `Q 键`：终结爆发大招（消耗满能量触发高额爆发或控制）。

## 3. 原神式 HUD、无锁剧情与界面重构

- **界面彻底重塑**：
  - **完全移除原版 9 格快捷栏、原版血条、饱食度与原版经验条**，彻底脱离传统生存 MC 观感。
  - **原神式常驻 HUD**：
    - 右侧：1-4 角色头像、独立生命值数值条与大招充能圆环。
    - 右下方：战技（E）CD 冷却扇形倒计时、大招（Q）能量环发光充能提示、翻滚闪避耐力条。
    - 屏幕中央底部：无锁移动剧情字幕（通讯电台对白）。
    - 屏幕右上方：当前主线任务标题、子目标进度、目标距离提示（如 `[前往反应堆 32m]`）。
- **原神式无限分类大背包 (Infinite Categorized Bag)**：
  - **彻底废除原版 27 格背包与掉落拾取困扰**。
  - 按 `B` 开启全屏现代化分类背包界面，划分为：
    1. **武器库**（所有持有的体素专武，点击可装备、强化、突破）
    2. **芯片库**（5个部位的科技芯片，支持按主词条/等级筛选与锁定）
    3. **材料库**（无堆叠上限，收纳矿石、掉落物、突破零件）
    4. **贵重物/任务**（关键剧情证物、星舰通行卡、星辉算力抽卡代币）
- **无锁移动对白（Radio Banter）**：
  - 绝大部分通讯与剧情对白通过屏幕底部动态逐字播报，不阻断玩家的移动与探索。
  - 只有在重大剧情分支抉择或关键首领过场时，才进入定格视角的对话界面。
- **传送锚点（Teleport Waypoints）**：
  - 飞船各关键甲板、异星矿区设有体素科技传送锚点。
  - 玩家按 `F` 激活后，可随时从地图界面快速传送，并提供小队快速复苏。

## 4. 装备与养成体系

- **角色专武**：全体素像素建模，拥有专属副词条与武器被动技能。
- **科技芯片（5件套）**：
  - 控制核心、动力发生器、能源电池、超频芯片、神经感知环。
  - 拥有 2 件套与 4 件套专属科技效果。
- **终端数据复现（抽卡）**：
  - 探索星舰与完成任务获得星辉代币。
  - 终端复现可抽取专武与“记忆碎片”（命座），满命可带来角色机制质变。
