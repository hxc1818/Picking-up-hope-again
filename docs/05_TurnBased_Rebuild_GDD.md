# 《重拾希望 (Picking up hope again)》v2.0 回合制重塑与新手篇策划案

> **版本**：v2.0  
> **核心定位**：太空工业科幻 · 星铁式回合制 RPG（大地图探索遇敌 + 专属独立战斗舞台）  
> **文风准则**：全程使用平实、自然、直白的工程与日常用语，全面去掉复杂、中二或浮夸的词汇。  
> **篇幅目标**：重塑并扩展为一个约 4 小时体验的新手教程篇章，用于完整介绍世界观、建立战斗理解，并搭建稳健可控的 1~80 级养成体系。

---

## 1. 核心玩法转向：星铁式回合制战斗

彻底取消原有的即时挥砍与 1~4 号位实时切人玩法，全面转向大地图探索与回合制排轴对战分离的架构：

### 1.1 大地图探索与进战机制
- **大地图自由探索**：玩家以第三人称视角在飞船舱区与异星地表跑动、跳跃、翻找补给箱、查看终端记录、与船员对话。
- **遇敌与先手判定**：
  - 怪物在大地图内固定区域巡逻或警戒。
  - **先手开战**：玩家接近怪物时按左键挥动武器命中怪物，触发“先手进战”，进入战斗后敌方全体直接扣除一截初始韧性条，我方占得先机。
  - **被偷袭**：如果被巡逻怪物从背后撞上或先手接触，触发“被偷袭”，进战后敌方行动条提前。
- **专属独立战斗空间**：
  - 触发战斗时播放屏幕转场动画，将双方传至平坦规整的专用科幻战斗舞台，彻底规避复杂地形导致的卡墙、高低差穿模或掉坑问题。
  - 舞台内我方最多 4 人横向站成一排，敌方在正面一排对峙，采用固定战术侧后方视角，配合技能特写运镜。
  - 战斗胜利结算战利品后，玩家自动传回大地图遇敌前的位置，并移除刚刚击败的怪物。

### 1.2 回合制核心规则
- **行动条与速度**：界面左侧显示敌我双方的行动先后顺序（按各自【速度】数值动态排轴）。
- **共享战技点（SP）**：
  - 全队共享一个战技点池，上限 **5 点**（通常 3 点开局）。
  - **普通攻击（Q）**：造成单体伤害，**恢复 1 点战技点**，同时为自己回复少量大招能量。
  - **战技（E）**：根据角色职业释放特色技能，**消耗 1 点战技点**，回复较多大招能量。
- **终结技插队（大招）**：
  - 角色能量积满 **100%** 后，右下角/右侧头像高亮提示。
  - **随时插队机制**：无论当前轮到谁行动（哪怕是敌人回合间隙），玩家随时按下数字键 `1~4` 或点击对应头像，即可立刻插队释放该角色的大招，且不消耗战技点。
- **键鼠双操作支持**：
  - **键盘快速流**：`Q` 选普攻、`E` 选战技、`A/D` 或 `Tab` 切换敌方目标、`1~4` 释放对应角色大招、`Space` 确认释放。
  - **鼠标直接点击**：呼出鼠标光标后，可直接点击屏幕下方技能图标和画面中的敌人完成全部操作。

## 2. 属性与职业体系（彼此独立、命名直白）

角色拥有**属性**与**职业**两个完全独立互不绑定的维度。

### 2.1 四大基础属性（水、地、气、火）与弱点击破
每个怪物头顶都会显示**白色韧性条**以及 1~3 个**弱点属性图标**。使用对应属性攻击命中敌人即可削减其韧性；韧性归零触发**弱点击破**（造成破盾伤害、打断敌人蓄力并延后其行动）：

| 属性 | 击破附带效果 | 实战作用说明 |
| :--- | :--- | :--- |
| **水** | **减速** | 降低目标移动与行动条前进速度，明显推迟其下一回合出手时间。 |
| **地** | **破甲** | 震碎敌方护甲，降低目标防御力，使其接下来承受更高的直接伤害。 |
| **气** | **撕裂** | 附加持续流血状态，敌人每次轮到自己行动前都会损失生命值。 |
| **火** | **灼烧** | 附加火属性持续伤害，适合配合高频攻击或弱火敌人的快速击杀。 |

### 2.2 六大独立职业定位
任何属性都可以与以下任意一种职业搭配组合，职责一目了然：

1. **治疗**：负责为单个队友或全队回复生命值，并能清除冰冻、灼烧、流血等负面状态。
2. **拉盾**：为单个或全体队友套上护盾吸收伤害，或嘲讽敌人吸引火力，保证脆皮生存。
3. **对单**：拥有高倍率的单体伤害技能，专攻精英怪与 Boss 的单点爆破与快速削韧。
4. **对群**：技能覆盖敌方全体，擅长快速清场多只小怪。
5. **群单输出均衡**：技能对主目标造成较高伤害，同时对左右相邻目标造成溅射伤害，兼顾单体压制与清杂。
6. **增益**：为队友提供加攻击、加速、提升暴击或额外补充战技点等辅助效果。

## 3. 约 4 小时新手教程剧情：两段式主线架构

定位类似《崩坏：星穹铁道》开篇的黑塔空间站，节奏从容、不讲宏大空话，以“认识飞船与世界现状、一步步学会回合制战斗、在绝境下求生联络”为主线。**第一章主线流程免费赠送 2 名队友（主角 + 2 名免费队友 = 3 人基础队伍），其余角色通过抽卡系统扩充。**

### 3.1 前半段：飞船受损与紧急脱险（约 2 小时）
1. **静息休眠区苏醒**：
   - 主角（初期默认为实用输出定位，如【地】属性·群单输出均衡）因供电中断提前从休眠舱醒来，发现走廊照明熄灭、警报灯闪烁。
   - 通过墙面维修终端和散落记录了解基本背景：人类搭乘大型运输舰【重拾希望号】躲避母星灾变，但在深空航行途中遭遇撞击，舰体多处受损、内部安保机器逻辑错乱。
   - 教学大地图移动、互动、以及靠近第一台故障清扫机按左键先手进战，学会最基础的普攻与破盾。
2. **检修走廊遇险与 1 号免费队友加入**：
   - 穿过泄压受损的通道，遇到被几台安保无人机堵在气密门后的年轻巡检员（**赠送队友 1：气属性·对群**）。
   - 教学两人配队、战技点循环（普攻攒点、战技消耗）以及如何用【对群】技能同时清掉多只小怪。
3. **动力机房抢修与 2 号免费队友加入**：
   - 二人前往下层动力机房试图恢复舰桥联络，在机房内救出正被机器人围攻的船舱医疗员（**赠送队友 2：水属性·治疗**）。
   - 教学三人编队、血线管理、使用治疗战技回血，以及能量满后按数字键随时插队释放大招急救。
4. **结构断裂与乘坐逃生舱撤离**：
   - 勉强启动备用电源后，控制台警报确认主船体龙骨已经严重开裂，该舱段即将失压脱落。
   - 三人被迫冲向轨道逃生舱并强行弹射脱离，坠向近地轨道下方的一颗冰封废矿星球。

### 3.2 后半段：迫降冰原与科考站决战（约 2 小时）
1. **冰原坠毁与野外求生**：
   - 逃生舱坠落在零下数十度的极寒冰裂谷。三人检查逃生舱黑匣子与周围残骸，捡取早期遗留的补给物资。
   - 教学材料收集与**低级材料合成高级材料**，并第一次用经验道具给角色手动升级。
2. **废弃地面科考站探索**：
   - 沿应急无线电信号找到早年人类搭建的废弃极寒科考站。
   - 在科考站安全屋内解锁**装备溶解与强化系统**，以及早期**模拟训练终端（日常材料副本）**。
   - 排查生活区与配电房，打开封锁大门的供电开关，清理盘踞在站内的旧式安保机械犬与重型巡检机。
3. **深入地下采掘矿坑**：
   - 修通科考站中央的货运升降梯，下到深埋在冰层下面的废弃工业矿坑。
   - 穿过布满管道与废旧矿车的挖掘通道，在矿坑底部发现还在依靠残余地热维持待机的旧时代重型机械。
4. **关底 Boss 战与教程收尾**：
   - 强行启动矿坑末端的深空信号发射塔，震动唤醒了守卫核心的【大型工程挖掘机】。
   - 击败 Boss 后夺回可用反应堆零件，接通通讯塔发出求救与坐标信号，终于和飞船主力幸存船员重新取得联络。
   - 系统正式解锁**抽卡界面（星海跃迁动画）**与完整日常刷取副本，新手教程到此顺利收官。

## 4. 关底 Boss 机制设计：大型工程挖掘机（双阶段策略战）

为了解决此前 Boss 战过快、纯靠数值碾压的问题，关底 Boss 改为明确的双阶段机制战：

```
┌──────────────────────────────────────────────────────────┐
│ 第一阶段：击破左右两条机械臂                              │
│  · 左挖掘臂（弱地）  /  右重锤臂（弱气）                   │
│  · 本体受护罩保护，免伤极高                                │
│  · 拆毁双臂后护罩碎裂，Boss 陷入 1 回合瘫痪，防御清零      │
└────────────────────────────┬─────────────────────────────┘
                             │ 血量进入二阶段 / 转阶段演出
                             ▼
┌──────────────────────────────────────────────────────────┐
│ 第二阶段：炉心过载与限时打断                              │
│  · 本体暴露【水】【火】双弱点                              │
│  · 行动条出现“全屏高温喷射”2回合蓄力倒计时                │
│  · 玩家必须算好战技点与大招，在倒计时前削空韧性条打断       │
└──────────────────────────────────────────────────────────┘
```

- **打断奖励与惩罚**：
  - 成功在蓄力完成前打断：Boss 过载反噬，自身扣除大量血量并推迟行动条，给予玩家一轮安全输出窗口。
  - 未能及时打断：Boss 释放全屏高额热浪攻击，并对全员附加【灼烧】，极易导致减员甚至团灭。

## 5. 1~80 级数值体系、材料层级与装备规则

全面解决此前“等级静态、掉落泛滥、升级过快、数值膨胀”的问题，建立严格的长期养成体系：

### 5.1 玩家主等级、世界等级与角色等级
- **角色等级区间**：**1 ~ 80 级**。
- **玩家主等级与世界等级联动**：
  - 玩家拥有自己的账号主等级（开拓等级）和当前世界等级。
  - 当主等级达到特定阶段门槛（如 20 级、30 级、40 级、50 级、60 级、65 级），必须完成一次**世界等级突破试炼**。
  - **突破限制**：如果不突破世界等级，角色的最高等级上限就会卡在当前档位无法继续突破；突破后世界等级上升，野外与副本敌人变强、高阶材料解锁掉落，角色上限开放至下一阶段。
- **角色升级途径**：
  - **打怪不直接给角色涨经验**。
  - 必须使用专门的经验消耗品（如【经验电池 / 附魔之瓶】），在角色界面手动点击注能升级。

### 5.2 材料分级（1~6 级）与系统独立性
- **严控产出**：日常战斗和宝箱每次只掉落极少量低等级基础材料，杜绝开局一给一大把。
- **1~6 级同系列材料合成**：
  - 同一系列材料严格分为 1 级到 6 级（例如：1 级粗糙零件 -> 2 级标准轴承 -> 3 级精密齿轮 -> ... -> 6 级核心模组）。
  - 低级材料可以通过工作台或合成界面合成为高一级材料（如 3 个低级合成 1 个高一级）。角色或武器等级越高，突破所需材料的等级和数量也越高。
- **三线材料完全独立**：
  1. **角色突破材料**（仅用于突破角色等级上限）
  2. **武器突破材料**（仅用于武器突破，种类完全独立于角色材料）
  3. **天赋升级材料**（仅用于提升普攻、战技、终结技与被动天赋的技能等级）

### 5.3 专门刷取副本（模拟终端）
在飞船安全区及科考站终端开放消耗体力的常驻副本，按需求定向刷取：
1. **信用点副本**：刷取通用金币。
2. **经验道具副本**：刷取角色升级用的经验电池/附魔之瓶。
3. **材料与天赋副本**：分别产出角色突破材料、武器突破材料和各职业天赋书。

### 5.4 装备（芯片）养成与分级规则
- **极其珍贵的升级体验**：
  - 装备**绝对不能通过战斗获得经验升级**。
  - 装备升级材料极其稀缺：**主要来源只有“溶解（分解）其他多余不用的装备”来换取强化经验，以及极个别主线/支线任务奖励的一丁点专属强化素材**。
- **装备星级（2~5 级装备）与等级上限**：
  - 装备分为 **2 级（2星）、3 级（3星）、4 级（4星）、5 级（5星）** 共四个档次：
    - **2 级装备**：最高可强化至 **9 级**
    - **3 级装备**：最高可强化至 **12 级**
    - **4 级装备**：最高可强化至 **15 级**
    - **5 级装备**：最高可强化至 **18 级**（最高即 18 级，每高一星满级上限提升 3 级）
- **副词条解锁与成长**：
  - **每提升 3 级**（+3、+6、+9、+12、+15、+18），解锁一条新副词条，或在词条满额时随机强化提升一条已有副词条的数值。

## 6. UI 全面美化、抽卡动画与资产细节规划

### 6.1 装备与角色界面彻底翻新
彻底放弃当前简陋粗糙的界面样式，采用深空灰黑底色配冷金属边框的现代分栏排版：
- **装备总览页**：左侧展示人体/芯片插槽分布与装备星级框；中间清楚展示当前白字基础属性与装备提供的绿字加成对比；右侧展示主副词条列表，并提供便捷的“一键放入低星多余装备溶解强化”预览窗口，清楚标出强化后每 3 级跳动的词条预览。
- **合成与副本页**：清晰列出 1~6 级材料阶梯树和合成数量滑块。

### 6.2 抽卡（祈愿）动画制作
实现带有视觉反馈的星海跃迁动画流程：
1. 点击【单抽】或【十连】后，进入全屏星空跃迁动画，画面中央出现高速穿行的光束。
2. 根据本次抽取的最高品质呈现不同颜色流星特效：**蓝光（3星武器）、紫光（4星角色/武器）、金光（5星角色/武器）**。
3. 随后逐张翻牌弹出抽中物品的立绘/模型展示卡（标注属性、职业、星级），底部提供【跳过】按钮与十连汇总页。

### 6.3 模型外观与灰盒场景细节补充
- **武器与装备图标外观**：为水/地/气/火各类武器与 2~5 级装备补齐清晰可辨的体素模型与 2D 图标，不再共用占位图。
- **灰盒地图打磨**：
  - **飞船前半段**：扩建休眠舱、泄压受损走廊、动力管道间与逃生舱发射坪，增加应急黄灯、破损铁丝网、蒸汽排气口、散落箱柜与维修工位细节。
  - **冰原后半段**：搭建逃生舱坠毁雪坑、被风雪半掩的科考站铁皮建筑、暖色安全屋灯火，以及地下矿坑的架空钢架、铁轨、矿车与挖掘机Boss决战圆台。
