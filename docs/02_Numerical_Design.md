# 《Picking up hope again（重拾希望）》数值体系与养成规范书 (v2.0)

> **版本**：v2.0（回合制重塑版）  
> **核心准则**：严控材料产出与数值成长曲线，彻底杜绝等级静态与前期数值膨胀。

---

## 1. 玩家主等级、世界等级与角色等级

1. **角色等级范围**：**1 ~ 80 级**。
2. **玩家主等级与世界等级联动**：
   - 玩家账号拥有独立的主等级（开拓等级）与世界等级。
   - 当主等级提升至阶段上限门槛（20 / 30 / 40 / 50 / 60 / 65 级）时，必须完成对应的**世界等级突破试炼**。
   - **限制机制**：突破世界等级前，所有角色的等级突破上限将被锁死在当前档位（例如新手教程期世界等级 0，角色上限锁在 20 级）；完成突破后世界等级提升，野外与副本敌人强度同步上调，高阶材料解锁产出，角色方可继续突破至下一阶段。
3. **角色升级方式**：
   - **普通战斗不直接给角色涨经验**。
   - 必须消耗专用经验道具（如经验电池 / 附魔之瓶），在角色界面手动点击注能升级。

## 2. 回合制战斗核心属性与公式

### 2.1 单位属性池
- **生命上限 (HP)**：1 级初始约 700~1000，80 级满级约 6,000~11,000。
- **攻击力 (ATK)**：角色白字基础攻击 + 武器攻击力，再叠加芯片的百分比与固定值加成。
- **防御力 (DEF)**：基础减伤基准与部分拉盾/防御向角色技能倍率来源。
- **速度 (SPD)**：决定行动条排轴顺序与行动频率（基础速度普遍在 95~125 之间）。
- **暴击率 / 暴击伤害**：基础暴击率 5%，基础暴击伤害 50%。
- **效果命中 / 效果抵抗**：影响水/地/气/火击破异常状态或减益的触发与抵抗概率。

### 2.2 伤害计算模型
$$\text{最终伤害} = \text{基础伤害} \times (1 + \text{属性/通用增伤}) \times \text{暴击系数} \times \text{防御系数} \times \text{抗性系数} \times \text{易伤系数}$$
- 怪物韧性条未击破时保有基础 **10% 韧性减伤**；弱点击破后减伤消失，并触发对应属性破盾伤害与异常状态（水减速、地破甲、气撕裂、火灼烧）。

## 3. 材料分级（1~6 级）与独立获取规划

### 3.1 产出克制原则
- 大世界宝箱与普通巡逻怪每次仅掉落**极少量低级材料**，从源头防止前期战力溢出。
- **低级合成高级**：同一系列材料共划分 **1 级到 6 级**，低级材料可在合成面板按比例合成为高一阶材料。角色、武器与天赋等级越高，消耗的材料阶数与数量越高。

### 3.2 三套材料完全独立
1. **角色突破材料**：专属用于突破角色 20/30/40/50/60/70 级上限。
2. **武器突破材料**：与角色突破材料完全独立，按近战/远程/工程等武器系列单独划分 1~6 级。
3. **天赋升级材料**：独立用于提升普通攻击、战技、终结技与被动天赋的技能等级。

### 3.3 模拟终端副本（日常体力消耗）
在安全区模拟终端开放以下常驻副本供稳定刷取：
- **信用点副本**：产出通用货币。
- **经验道具副本**：产出经验电池 / 附魔之瓶。
- **材料与天赋副本**：定向刷取各阶段人物突破材料、武器突破材料与天赋升级材料。

## 4. 装备（芯片）分级与强化体系

### 4.1 稀缺的强化经验规则
- **战斗不产生任何装备经验**。
- 装备强化素材极为珍贵：**唯一主要获取方式是溶解（分解）其他多余的废弃装备**，以及极少数重要任务奖励的微量专用强化材料。

### 4.2 装备级别与满级阶梯（2~5 级装备）
装备按照品质分为 **2 级、3 级、4 级、5 级**（对应 2 星 ~ 5 星），每高一级装备，满级上限提高 3 级：

| 装备品质级别 | 最高强化上限 | 副词条触发节点 | 说明 |
| :--- | :--- | :--- | :--- |
| **2 级装备（2星）** | **9 级** | +3 / +6 / +9 | 前期过渡用基础件 |
| **3 级装备（3星）** | **12 级** | +3 / +6 / +9 / +12 | 新手教程后半段实用件 |
| **4 级装备（4星）** | **15 级** | +3 / +6 / +9 / +12 / +15 | 中期主力毕业件 |
| **5 级装备（5星）** | **18 级** | +3 / +6 / +9 / +12 / +15 / +18 | 最高品质终极毕业件 |

### 4.3 副词条机制
- 装备**每提升 3 级**（+3、+6、+9、+12、+15、+18），自动解锁一条新副词条；当副词条数量已满（4条）时，改为随机强化并提升其中一条已有副词条的数值。

## 5. 抽卡（祈愿）与保底机制

1. **抽卡消耗**：使用任务探索、活跃或兑换获得的抽卡券。
2. **保底规则**：
   - 10 连抽必出 4 星或以上角色/武器。
   - 最多 80/90 抽触发 5 星最高品质保底。
   - 新手期提供专属折扣新手池，确保玩家顺利组建完整的水/地/气/火多职业队伍。
