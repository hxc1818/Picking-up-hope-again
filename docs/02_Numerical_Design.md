# 《Picking up hope again》数值体系与公式设计规范书 (Numerical Design Document)

> **版本**：v1.0  
> **设计目标**：建立稳定、可扩展、兼具动作操作上限与策略构筑深度的 ARPG 数值体系。对齐《原神》多乘区理论与《流浪地球》重工业装备调性。

---

## 1. 核心属性定义与属性池

每个角色与敌方单位均挂载以下核心底层属性：

| 属性名称 | 代码标识符 | 基础类型 | 说明 / 设定基准 |
| :--- | :--- | :--- | :--- |
| **生命值上限** | `max_health` | 基础值 + 百分比 | 1级初始生命 800 ~ 1200，满级（80级）约 12,000 ~ 18,000 |
| **基础攻击力** | `base_atk` | 白字攻击 | 角色自身基础攻击 + 装备武器主攻击力（所有百分比攻击力加成以此为基数） |
| **附加攻击力** | `extra_atk` | 绿字攻击 | 芯片（圣遗物）固定值攻击力 + 词条百分比攻击力加成 |
| **基础防御力** | `defense` | 数值 | 减伤基准，1级初始约 400，满级约 700 ~ 900 |
| **暴击率 (CRIT Rate)** | `crit_rate` | 百分比 | 初始基础 **5.0%**，上限 100% |
| **暴击伤害 (CRIT DMG)**| `crit_dmg` | 百分比 | 初始基础 **50.0%** |
| **能量充能效率 (ER)** | `energy_recharge`| 百分比 | 初始基础 **100.0%**，提升战技粒子转化大招能量的倍率 |
| **元素/科技精通** | `tech_mastery` | 数值 | 提升超导、感电、热核聚变等复合反应伤害与护盾强效 |
| **对应属性伤害加成** | `damage_bonus` | 百分比 | 电浆、热能、动能物理、冷凝、磁暴伤害独立加成 |

## 2. 核心战斗伤害公式 (Multi-Multiplier Formula)

最终前台造成的实际伤害计算公式采用标准**六乘区模型**：

$$\text{Final Damage} = \text{ATK} \times \text{Skill\%} \times (1 + \text{DMG\_Bonus}) \times \text{CRIT} \times \text{DEF\_Multiplier} \times \text{RES\_Multiplier}$$

### 2.1 攻击区 (ATK)
$$\text{Total ATK} = \text{Base ATK} \times (1 + \sum \text{ATK\%}) + \text{Flat ATK}$$

### 2.2 技能倍率区 (Skill%)
- **普攻连击**：1段 65% ~ 80% $\to$ 2段 70% ~ 90% $\to$ 3段 95% ~ 120% $\to$ 4段终结击 140% ~ 180%。
- **科技战技 (E)**：单段爆发型（180% ~ 350%，CD 6~10s）或 持续脱手型（每秒 40% ~ 70%，持续 8s，CD 12s）。
- **终结爆发 (Q)**：消耗 60 ~ 80 点能量，瞬时爆发 600% ~ 1200% 或 全场持续协同 15s。

### 2.3 暴击区 (CRIT)
- 未暴击：$1.0$
- 暴击触发：$1 + \text{CRIT\_DMG}$
- 期望伤害系数：$1 + (\text{CRIT Rate} \times \text{CRIT DMG})$

### 2.4 敌方防御减伤区 (DEF Multiplier)
参考标准防御公式，有效平衡高低级压制：
$$\text{DEF\_Multiplier} = \frac{\text{Attacker Level} + 100}{(\text{Attacker Level} + 100) + (\text{Enemy Level} + 100) \times (1 - \text{DEF Reduction})}$$
- 同等级敌人（双方均50级）基础减伤刚好为 $0.5$（即承受50%伤害）。

### 2.5 抗性区 (RES Multiplier)
敌人基础各属性抗性默认为 $10\%$：
- 当 $\text{RES} \ge 0$ 时：$\text{RES\_Multiplier} = 1 - \frac{\text{RES}}{100}$
- 当 $\text{RES} < 0$ 时（减抗）：$\text{RES\_Multiplier} = 1 - \frac{\text{RES}}{200}$

## 3. 科技芯片（圣遗物）词条库与强化数值阶梯

共 5 个芯片插槽：
1. **控制核心 (Slot 1)**：固定主词条为 `生命值 (HP Flat)`
2. **动力发生器 (Slot 2)**：固定主词条为 `攻击力 (ATK Flat)`
3. **能源电池 (Slot 3)**：可随机主词条为 `百分比攻击` / `百分比生命` / `充能效率` / `科技精通`
4. **超频芯片 (Slot 4)**：可随机主词条为 `属性伤害加成 (电浆/热能/物理等)` / `百分比攻击`
5. **神经感知环 (Slot 5)**：可随机主词条为 `暴击率` / `暴击伤害` / `百分比攻击` / `治疗加成`

### 3.1 词条强化档位表（以金色5星满级20级为例）
- 初始拥有 3~4 条副词条，每强化 4 级随机强化一次副词条（共 5 次提升机会）。
- 暴击率单次强化值：`2.7% / 3.1% / 3.5% / 3.9%`
- 暴击伤害单次强化值：`5.4% / 6.2% / 7.0% / 7.8%`
- 攻击力百分比：`4.1% / 4.7% / 5.3% / 5.8%`

## 4. 充能微粒与大招能量循环 (Energy Recharge Economy)

1. **战技产球**：
   - 角色释放 E 技能命中敌人，生成 2 ~ 4 颗对应属性的“量子微粒”。
2. **能量吸收收益**：
   - **前台同属性角色**：每颗微粒提供 $3.0 \times \text{ER}$ 能量。
   - **后台同属性角色**：每颗微粒提供 $1.8 \times \text{ER}$ 能量。
   - **前台异属性角色**：每颗微粒提供 $1.0 \times \text{ER}$ 能量。
   - **后台异属性角色**：每颗微粒提供 $0.6 \times \text{ER}$ 能量。
3. **能量上限档位**：
   - 战技型副 C / 盾辅：40 ~ 60 能量点。
   - 强力全屏爆发 / 逆转战局大招：80 点能量（需堆叠 160%~200% 充能效率以维持回转）。

## 5. 终端复现（抽卡）与记忆碎片（命座）数值

1. **抽卡代币**：`星辉算力芯片 (Star-Core Token)`
   - 探索宝箱获取：小宝箱 2 个，工业密闭舱 5 个，章节首通 40~100 个。
   - 单抽消耗：160 个。
2. **保底机制**：
   - 角色/专武保底：最多 80 次抽取必定触发金色传说级产出（专武或高阶记忆体）。
3. **记忆碎片（命座 1~6）提升幅度**：
   - **1命**：核心战技使用次数 +1 或 能量消耗降低 20%。
   - **2命**：战技命中降低敌人防御力 15%~20%（质变辅助命座）。
   - **3命**：战技技能等级 +3（提升约 18% 倍率）。
   - **4命**：后台协同效果增强或提供队伍护盾/霸体。
   - **5命**：终结技等级 +3。
   - **6命**：角色核心机制质变（例如变身普攻附加范围属性溅射，化身完全体）。
